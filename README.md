# 酷安桌面端

基于用户提供的酷安 **16.6.4 / 2609291** APK 做协议分析的非官方 Windows 桌面客户端。Electron 44 + React + TypeScript，直接连接酷安服务，不需要把手机持续连接在电脑上。

这是可运行的开发版，尚未达到手机客户端所有功能的完整复刻。界面使用真实接口数据，没有演示帖子替代联网结果。

## 使用

双击 `release/Coolapk-Desktop-0.2.0-x64.exe`。便携版会在启动时解压运行时；账号数据保存在 Windows 应用数据目录。源码同步到 [Z-YO-YI/coolapk-for-windows](https://github.com/Z-YO-YI/coolapk-for-windows)，每次推送 main 自动构建 Windows x64 便携版，可在对应 Actions 构建的产物中下载。

公开首页、热榜、搜索和用户主页可以直接浏览。左下角“登录酷安”打开官方网页，用户自行扫码或输入验证码；登录完成后尝试通过官方授权码接口建立会话。已有本人 Cookie 也可手动导入，导入时先校验账号。

如果详情或评论提示“酷安要求安全验证”，点击“完成验证”，在单独窗口亲自完成网易易盾验证。服务端决定验证是否通过；程序不自动解题，也不把验证失败当作空列表。

快捷键：`Ctrl+K` 搜索、`Ctrl+R` 刷新、`Alt+←` 返回、`Esc` 关闭弹窗。图片窗口支持左右方向键。Windows 原生菜单和文本右键菜单可用。

## 开发

需要 Node.js 24+ 和 pnpm 11.25.0。本项目使用 `pnpm-lock.yaml` 锁定依赖，依赖构建授权及项目内缓存路径在 `pnpm-workspace.yaml` 中。

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm test
pnpm package
```

`pnpm test:desktop` 使用项目 Playwright 依赖运行 Electron 交互检查，需要可连接酷安服务。测试使用独立的 `.local/ui-check/userdata`，不会读取用户的正常账号库。`pnpm test:package` 检查打包后的程序。依赖、APK、反编译临时文件与测试账号目录均不进入 Git。

`pnpm exec playwright install chromium` 后运行 `pnpm test:features` 和 `pnpm test:media`，可执行隔离的收藏单、评论配图、私信、人工验证重试及账号切换交互检查。它们模拟 API 并拦截外部网络，适用于 CI；本机已有 Chrome 时可设置 `PLAYWRIGHT_BROWSER_CHANNEL=chrome`。

## 结构

- `core/auth.mjs`：16.6.4 Token V3 签名和设备码。
- `core/client.mjs`：API 契约、分页、登录拦截和错误处理。
- `core/upload.mjs`：官方 OSS 图片上传，上传凭据留在主进程。
- `core/images.mjs`：限制公开 CDN 图片来源；私信图片仅调用固定官方接口，限制响应 MIME 和大小。
- `core/account-store.mjs`：原子写入的系统加密账号库。
- `electron/`：原生壳、受限 IPC、官方登录和人工验证窗口。
- `src/`：桌面界面与交互。
- `scripts/analyze-apk.py`：可复现的 APK / libauth 分析。
- `research/`：脱敏的协议证据和验证结果。
- `.local/`：反编译工具、临时分析源码及测试截图，不参与打包。

## 数据与网络

账号 Cookie 使用 Electron `safeStorage` 调用 Windows 系统加密，写入 `accounts.encrypted`，不会进入前端账号状态、日志或项目源码。浏览历史保存在本机，最多 150 条，可清空。游客设备码由本机随机生成并保存，不读取手机的设备标识或账号凭据。

API 请求固定指向 `https://api.coolapk.com`。公开图片代理只允许已列明的酷安 CDN 域名，不携带账号 Cookie；私信图片通过带账号认证的固定 `message/showImage` 接口读取，不进入公开图片缓存。OSS 上传仅允许经过校验的阿里云 OSS 域名；密钥不返回给界面。官方登录窗口和易盾窗口没有主界面的 API 桥接权限。账号切换后拒绝旧请求结果并关闭旧窗口。应用不收集遥测数据。
