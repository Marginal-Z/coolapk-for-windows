# 酷安桌面端

基于用户提供的酷安 **16.6.4 / 2609291** APK 协议分析开发的非官方 Windows 客户端，Electron 44 + React + TypeScript。源码同步至 [Z-YO-YI/coolapk-for-windows](https://github.com/Z-YO-YI/coolapk-for-windows)。

目标是完整复刻手机客户端功能：社区功能在桌面本机实现，Android 应用安装、系统权限、支付及依赖手机设备的直播操作通过 USB 手机协同完成。**当前 0.6.7 是开发版，完整复刻尚未完成。** [完整性审计](research/parity-gaps.json)保留未实现与协议未知项，不将镜像、网页入口或模拟测试算作完整原生功能。

## 使用

液态玻璃在「设置 → 界面显示 → 界面材质效果」中启用。折射按控件尺寸适配，侧栏使用移动的玻璃选中层；搜索、弹窗与内容沿用原主题。配合自定义背景可看到更明显的效果，正文保留阅读底色。实现、参考许可和验证范围见[液态玻璃接入说明](docs/liquid-glass.md)。

推荐从 [GitHub Releases](https://github.com/Z-YO-YI/coolapk-for-windows/releases/latest) 下载 `Coolapk-Desktop-Setup-0.6.7-x64.exe` 安装版，也提供 `Coolapk-Desktop-0.6.7-x64.exe` 便携版。安装后进入“设置 → 软件更新”，可检查新版本、查看更新说明、下载/取消/重试，以及确认退出并安装。每次启动只检查，下载和安装需要手动触发；关闭更新窗口不会中断下载。便携版收到新版本后可通过相同安装器迁移，账号、设置和草稿保留在本机用户目录。0.4.0 需先手动安装一次新版本。详见[更新与发布说明](docs/updating.md)。

推送 main 后自动构建安装版和便携版；版本标签通过全部检查后发布完整更新包和元数据。成功的 GitHub Actions 运行也提供 `Coolapk-Windows-x64` 产物。程序尚未进行代码签名；更新包依据 GitHub HTTPS 发布源及 SHA-512 校验，不宣称已签名。

GitHub 构建产物同时包含该次构建的 `release-manifest.json`，可核对同包 EXE 的 SHA-256。本仓库 `research/release-manifest.json` 记录本机交付包；不同构建的摘要应使用各自附带的清单。

公开浏览无需登录。左下角“登录酷安”打开官方登录窗口，由用户自行扫码或输入验证码；也可自行导入本人的 Cookie，导入时先校验身份。凭据使用 Windows 系统加密保存在本机，支持多账号切换。


0.6.7 将首页活动与十个快捷入口改为单行横向滚动，保留完整导航；滚轮和键盘可浏览全部项目，边界恢复页面滚动。缩小窗口时搜索栏为顶部发布与操作按钮让出空间，高缩放下保留全部入口。

0.6.6 增加“设置 → 关于酷安”，说明第三方非官方身份、权利归属和官方服务依赖，并显示原生版本、源码、反馈与更新入口。本轮从已连接手机首页核对全部 17 个官方栏目，补回轮播、10 个快捷入口、20 个兴趣入口、时间线与分组内容，以及官方 24 类话题切换；头条沿用首页固定入口。已确认的 22 个新只读列表使用固定路径和参数校验，应用/游戏搜索入口会聚焦顶栏并保留搜索类型。见[手机首页逐项清单](research/home-mobile-audit.json)、[导航及未适配入口](research/home-navigation-audit.json)和[真实桌面窗口检查](research/home-native-checks.json)。神券 SDK 回调、不可用的旧榜单和登录后状态仍单列为缺口。

0.6.6 的三种材质在六种主题、三类背景下分别验收，正文、小字、导航与控件的最小实测对比度超过 4.5:1；低透明度自动保护阅读区域，保存的滑块值保留。弹窗与按压使用短动效并遵守减少动态效果；缓存文本解析、避免嵌套材质重复过滤，并阻止重复/空页无限分页。[流畅度检查](research/desktop-motion-checks.json)记录固定合成负载和限制，不保证所有设备帧率。

原动态作者可按官方权限与剩余额度隐藏回复或取消隐藏。提交前重新读取原评论与动态确认身份，提交后读回 `block_status`；结果未确认时保留列表并只读核对，切换账号会丢弃旧结果。这项操作已有[静态合同](research/reply-visibility-contracts.json)和[隔离界面检查](research/reply-visibility-ui-checks.json)，真实账号写入与每日额度仍待验收。首页统一“更多”菜单、管理员推荐控制及独立评论编辑仍未完整实现。

0.6.3 的[更新日志](CHANGELOG.md)记录全局背景、宽屏双列、发布入口、自动分页、下载记录和手机熄屏等改动。0.6.4 修复系统减少透明度时材质失效的分支，默认使用软件材质并提供“跟随 Windows 透明效果”开关；高对比度始终使用纯色。默认背景图片／内容不透明度改为 60%／78%，只迁移旧版准确的默认组合，保留自定义值。三种模式分别提供清晰折射、磨砂模糊和原图透色，弹窗遮罩不再截断材质。下载跳转已只读取少量 APK 文件头验收 `com.example.ourom` 的官方链，未保存完整 APK。安全锁仍需本人解锁，软件更新会显示本版或新版本的实际发布日志。

[全局材质验收](research/global-materials-checks.json)使用实际 Electron、背景存储协议和合成只读数据，覆盖三种效果、暗色／纯黑、降低透明度、高对比和小窗口；[自动分页验收](research/auto-pagination-checks.json)覆盖滚动、失败停止、保留数据、账号切换、弹窗与键盘入口。[下载链验收](research/download-live-checks.json)是实际匿名网络读取，约 32 KB 后取消。手机熄屏参数和日志界面已自动验收，安全锁解锁、整包下载与真实安装未在本次验收中执行。

游客读取动态与评论没有本机登录门槛，但官方仍可要求安全验证。0.6.2 已在独立的 D 盘游客目录中，使用实际主进程、preload 与界面，由用户亲自完成官方验证码后成功显示一次评论列表，共 31 条，见 [人工验证后的游客评论检查](research/guest-verification-live-check.json)。原来的独立详情验证提示仍保留；本次未验收完整详情、其他分页或登录账号的评论读取。界面支持明确提示、取消及重新打开验证，完成后只重试原来的详情或评论请求；楼中楼与排序已有隔离回归。发表和修改内容仍需登录。

本轮电脑网络下，官方登录页返回 EdgeOne 567，未显示登录表单，因此桌面测试账号尚未登录。登录被拦截会明确提示并保留已有账号；这批新增发布、编辑和云端配置只完成隔离测试，仍需登录成功后核对真实服务端结果。

提示安全验证时，点击对应提示中的“完成验证”，等待独立窗口显示滑块或点选题，按题目亲自完成。成功后窗口自动关闭，程序重读该提示对应的原请求，不需要粘贴验证码或凭证。0.6.2 的人工验收只确认一次评论列表成功，独立详情挑战仍未完成。0.6.3 增加已接受验证凭证的共享读取：验证成功后，同一账号范围内同时被拦截的详情与评论可再读一次；新的官方挑战仍会保留，不会自动重发任何写入。该共享流程使用隔离测试验收，尚未重新进行真实人工验证码验收。0.6.2 修复验证码脚本被验证页拦截的加载问题，模板执行例外仅用于独立验证码页，主应用的脚本权限不变；同时补齐官方 APK 使用的 API 内存验证 Cookie，这类凭证不写入账号文件，也不发送给易盾窗口。

若验证窗口提示加载超时或网络错误，可点击窗口内“重新加载”，仍失败时取消后重新打开验证。验证请求五分钟后失效，需返回内容页刷新，获取新挑战。程序仅重试仍属于当前账号和页面的原操作；切换账号、页面或关闭弹窗后，旧验证回调失效。失败仍显示错误并保留已加载内容。登录及互动受官方服务和账号权限限制。

“手机协同”检测 USB 调试授权并打开独立手机控制窗口，使用[官方 scrcpy Windows 发行版](https://github.com/Genymobile/scrcpy/blob/master/doc/windows.md)。固定 ZIP 的 SHA-256 校验通过后才解压打包；发行版包含 ADB、scrcpy 和许可证。鼠标点击/拖动、键盘输入、右键返回、中键回到手机桌面均可使用；剪贴板自动同步关闭。手机与桌面账号分别登录。安装 APK 需要选择文件并确认，更新使用 `adb install -r`。

应用详情中的“下载安装包”将官方可用版本加入“应用下载”队列，可查看进度、速度、错误，暂停、继续、取消或重新下载。完成后可打开文件、显示所在位置，或点击“安装到手机”，选择已授权设备并确认。下载完成和安装前分别校验文件一致性，队列不会自动安装。此流程已完成模拟验证，尚未使用真实应用下载和安装验收；支持带强文件标识的断点续传；暂停完成后保存文件摘要，重启后需用户主动继续。继续前重新核对官方版本和文件，标识不足或服务器忽略续传时重新下载。拆分安装包及第三方镜像仍未适配。

动态的“分享”可复制链接、选择配图、预览图文分享卡并保存 PNG，也可生成文字卡或导出 Markdown/JSON；图片查看器可保存服务端提供的原图。收藏单页面可按分页导出动态正文、来源链接和图片地址，读取中途失败时不保存部分结果。**收藏单导出当前仅支持动态类内容，附件不会随文档下载，不能作为所有收藏实体的完整备份。**

“我的”按同版本手机重新排列顶部工具、个人资料、动态/关注/粉丝计数和八个快捷入口。计数读取当前桌面账号，缺失值不假造；点评、图文、回复可直接打开对应分类，更多中的草稿箱、下载和设置连接到实际桌面功能。手机扫一扫、应用更新和应用管理通过手机协同入口继续。

0.6.1 调整桌面排版：侧栏标识使用本次提供的近景图片，并去掉“桌面端”副标题；搜索栏居于工作区中间。窗口扩大时信息流使用可用宽度并自动分栏，较窄窗口保留单栏。首页标题、管理栏目与栏目页签固定在内容区上方；点击刷新或按 `Ctrl+R` 回到当前滚动区域顶部，重新读取第 1 页，保留当前栏目和排序规则。应用列表改用紧凑网格，详情展示服务器返回的应用图标、介绍与截图，截图可打开大图；服务端未返回的图片不补造。

设置改为宽屏分类侧栏和双列总览，内容单独滚动；小窗自动切换为水平分类。设置支持 14 种配色和独立自定义主题/强调色、四种字号、系统及定时夜间模式，字号与原生菜单缩放组合。材质、回顶和 FPS 有实际效果；图片设置包含预览质量、实况声音和云端水印，上传按官方 OSS 处理流程生成结果。隐私与订阅的 20 项已确认字段采用云端读取、单项保存和读回核对，账号切换会废弃旧请求。本机历史按账号分区，关闭记录后清理对应本机记录并停止记录；旧版未分区记录不会自动归入任一账号。

“设置 → 界面显示 → 自定义背景”可通过系统选择器选择本机 JPEG、PNG 或 WebP，最大 16 MiB、单边不超过 8192 像素且总像素不超过 33,554,432（32 Mi 像素）。背景图片与内容区域分别调节不透明度，默认 60% 和 78%，文字本身不会随滑块变淡；也可停用或删除图片并恢复默认。图片副本保存在应用用户数据目录，通过固定受控协议显示，不把图片数据或文件路径写入浏览器偏好存储。低透明度时阅读区域会自动保留安全底色。Windows 高对比度会隐藏背景并使用实色；仅开启“跟随 Windows 透明效果”时，系统降低透明度设置会将材质改为实色。

青少年模式需要设置四位密码，启用后退出当前账号并切换官方精选内容；主进程执行每日 40 分钟和 22:00–06:00 限制，关闭模式和修改密码需要验证。精选来源、动态编号及图片地址由主进程核对，普通账号、搜索、发布、私信、手机协同及外链入口被限制；重启后仍保留模式。缓存清理实际清除公开图片与网页缓存，保留登录和下载文件。

快捷键：`Ctrl+K` 搜索、`Ctrl+R` 刷新、`Alt+←` 返回、`Esc` 关闭弹窗。支持窗口缩放、Windows 菜单与文本右键菜单。

## 开发

项目和缓存保存在 D 盘工作区。Windows 打包、Electron 原生测试及 USB 调试在 Windows 执行；Linux 服务、容器工作优先 WSL2 Ubuntu。本机 Ubuntu 可运行 Git，当前未安装 Node.js。

以下命令在 **PowerShell 7** 执行，需要 Node.js 24+、pnpm 11.25.0 和 PowerShell 7：

```powershell
pnpm install --frozen-lockfile
pnpm prepare:phone
pnpm dev
pnpm test
pnpm build
pnpm package
pnpm verify:release
```

## 结构与网络

- `core/`：固定接口、认证、账号、搜索、数码/应用、好物、社区、文章、视频、实况和加密账号库。
- `electron/`：受限 IPC、登录/账号/易盾窗口、下载队列、文件保存、USB 协同；前端没有 Node.js 或任意命令权限。
- `src/`：桌面导航、详情、资料、商品清单、下载及媒体编辑界面。
- `scripts/`、`tests/`：测试、只读探测、APK 分析和静态完整性审计。
- `research/`：脱敏报告；`.local/` 保存私有临时文件、截图和工具，默认不入 Git。

API 固定指向酷安服务。公开图片只接受列明的酷安 CDN，以及实际应用接口返回的 `pp.myapp.com` 固定图标/截图路径，不带账号凭据；私信图片和账号二维码使用认证接口且不进入公开图片缓存。OSS/COS 上传及 APK 下载校验目标地址，临时密钥不返回界面，Cookie/App Token 不发送给存储或 VOD。账号切换后停止旧请求的后续阶段和未完成下载。导出、原图保存及本机背景选择使用 Windows 文件对话框；背景副本只能通过其当前内容摘要对应的受控协议读取。远程网页没有主界面桥接权限。程序不收集遥测。许可证见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。
