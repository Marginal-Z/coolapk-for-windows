# 酷安桌面端

基于用户提供的酷安 **16.6.4 / 2609291** APK 协议分析开发的非官方 Windows 客户端，Electron 44 + React + TypeScript。源码同步至 [Z-YO-YI/coolapk-for-windows](https://github.com/Z-YO-YI/coolapk-for-windows)。

目标是完整复刻手机客户端功能：社区功能在桌面本机实现，Android 应用安装、系统权限、支付及依赖手机设备的直播操作通过 USB 手机协同完成。**当前 0.5.0 是开发版，完整复刻尚未完成。** [完整性审计](research/parity-gaps.json)保留未实现与协议未知项，不将镜像、网页入口或模拟测试算作完整原生功能。

## 使用

推荐从 [GitHub Releases](https://github.com/Z-YO-YI/coolapk-for-windows/releases/latest) 下载 `Coolapk-Desktop-Setup-0.5.0-x64.exe` 安装版，也提供 `Coolapk-Desktop-0.5.0-x64.exe` 便携版。安装后进入“设置 → 软件更新”，可检查新版本、查看更新说明、下载/取消/重试，以及确认退出并安装。每次启动只检查，下载和安装需要手动触发；关闭更新窗口不会中断下载。便携版收到新版本后可通过相同安装器迁移，账号、设置和草稿保留在本机用户目录。0.4.0 需先手动安装一次新版本。详见[更新与发布说明](docs/updating.md)。

推送 main 后自动构建安装版和便携版；版本标签通过全部检查后发布完整更新包和元数据。成功的 GitHub Actions 运行也提供 `Coolapk-Windows-x64` 产物。程序尚未进行代码签名；更新包依据 GitHub HTTPS 发布源及 SHA-512 校验，不宣称已签名。

GitHub 构建产物同时包含该次构建的 `release-manifest.json`，可核对同包 EXE 的 SHA-256。本仓库 `research/release-manifest.json` 记录本机交付包；不同构建的摘要应使用各自附带的清单。

公开浏览无需登录。左下角“登录酷安”打开官方登录窗口，由用户自行扫码或输入验证码；也可自行导入本人的 Cookie，导入时先校验身份。凭据使用 Windows 系统加密保存在本机，支持多账号切换。

提示安全验证时，点击“完成验证”，在独立窗口亲自完成官方易盾验证。程序仅重试仍属于当前账号和页面的原操作；切换账号、页面或关闭弹窗后，旧验证回调失效。失败仍显示错误并保留已加载内容。登录及互动受官方服务和账号权限限制。

“手机协同”检测 USB 调试授权并打开独立手机控制窗口，使用[官方 scrcpy Windows 发行版](https://github.com/Genymobile/scrcpy/blob/master/doc/windows.md)。固定 ZIP 的 SHA-256 校验通过后才解压打包；发行版包含 ADB、scrcpy 和许可证。鼠标点击/拖动、键盘输入、右键返回、中键回到手机桌面均可使用；剪贴板自动同步关闭。手机与桌面账号分别登录。安装 APK 需要选择文件并确认，更新使用 `adb install -r`。

应用详情中的“下载安装包”将官方可用版本加入“应用下载”队列，可查看进度、速度、错误，暂停、继续、取消或重新下载。完成后可打开文件、显示所在位置，或点击“安装到手机”，选择已授权设备并确认。下载完成和安装前分别校验文件一致性，队列不会自动安装。此流程已完成模拟验证，尚未使用真实应用下载和安装验收；支持带强文件标识的断点续传；暂停完成后保存文件摘要，重启后需用户主动继续。继续前重新核对官方版本和文件，标识不足或服务器忽略续传时重新下载。拆分安装包及第三方镜像仍未适配。

动态的“分享”可复制链接、选择配图、预览图文分享卡并保存 PNG，也可生成文字卡或导出 Markdown/JSON；图片查看器可保存服务端提供的原图。收藏单页面可按分页导出动态正文、来源链接和图片地址，读取中途失败时不保存部分结果。**收藏单导出当前仅支持动态类内容，附件不会随文档下载，不能作为所有收藏实体的完整备份。**

“我的”按同版本手机重新排列顶部工具、个人资料、动态/关注/粉丝计数和八个快捷入口。计数读取当前桌面账号，缺失值不假造；点评、图文、回复可直接打开对应分类，更多中的草稿箱、下载和设置连接到实际桌面功能。手机扫一扫、应用更新和应用管理通过手机协同入口继续。

设置中的“界面显示”支持跟随系统/大号/标准/小号、白色/黑色/纯黑、跟随系统夜间模式和自定义夜间时段。字号作用于实际 Electron 窗口，并与菜单缩放组合；重置缩放保留字号选择。缓存清理实际清除公开图片与网页缓存，保留登录和下载文件；清空本地浏览历史与云端历史分别处理。其它手机配色、材质、图片水印、隐私与订阅提醒仍待实现。

快捷键：`Ctrl+K` 搜索、`Ctrl+R` 刷新、`Alt+←` 返回、`Esc` 关闭弹窗。支持窗口缩放、Windows 菜单与文本右键菜单。

官方搜索类别为综合、应用、游戏、酷友、动态、问答、数码、话题、酷安号、应用集、二手、好物、好物榜；“提问”和“回答”是问答类别的过滤别名。输入建议支持方向键选择、Enter 确认、Esc 关闭，建议失败时仍可直接搜索。首页“管理栏目”支持本机排序和显隐；登录后可将服务端返回编号的官方栏目提交账号同步。账号二维码使用认证图片接口，切换账号会关闭旧二维码；异常动态和回收站的读取权限由酷安服务决定。

首页另有“快讯”和“社区精选”，分别使用已确认的新闻栏目和社区精选列表；热榜支持收藏榜及指数榜。评论“热门讨论”使用独立的讨论列表接口，与“热门评论”分别保留；只看楼主或隐藏评论时使用对应的已确认列表。

应用推荐榜、最新应用、热门游戏关键词，以及游客酷友资料、公开主页和应用节点讨论已有单项只读实测；应用评分的公开样本为空，仍待真实数据验证。应用/游戏分类按钮使用参考协议确认的固定关键词，不代表完整官方分类目录。列表分页失败后“重试”或“完成验证”重复失败页并保留已加载内容。

公开首页、图片、搜索、产品分类、品牌、应用版本、应用集、酷安号、活动及图库已有只读实测；手机已更新到 16.6.4 并验证协同窗口启动和视频渲染。新增好物、下载、分享、搜索建议、账号内容及状态功能有协议单元和模拟界面测试，账号中心与搜索另有实际 Electron 界面验证。分享卡已生成可解码 PNG，发布视频使用真实合成 MP4 解码生成 JPEG 封面；下载/USB 安装交接、保存操作及账号写入使用模拟服务或模拟 IPC 验证。**没有向真实账号发帖、发私信、投票、举报、修改资料、创建好物清单或删除内容；模拟测试不代表真实写入已验收。** 脱敏证据见 `research/` 中相应能力与检查报告。

手机登录后已只读核对 16.6.4 的“我的”、更多、界面显示、图片、隐私、订阅提醒及动态发布工具栏，脱敏清单见 [手机功能基线](research/mobile-ui-baseline.json)。按用户明确选择，仅在手机首次发布提示中订阅了回复通知，没有发布动态。手机登录不会自动登录桌面账号；本轮账号读取、发布工具和设置的界面测试使用合成数据，原生设置另验证真实 Electron 字号、菜单、系统主题和缓存接口。

未完成项包括举报、创建提问/投票、完整二手交易闭环、视频重新编辑、活动报名、完整隐私/账号安全设置、装备/抽奖/备份、首页节点/关键词屏蔽、全部配色和图片设置、所有特殊卡片及平台限定状态。好物产品专辑的发布后编辑/删除、异常动态申诉/恢复没有可靠契约；商品详情外链不代表桌面已完成购物支付流程。`research/parity-gaps.json` 逐项列出证据、状态及下一步；静态源码映射数量不是手机客户端完成率。尚需逐项扩展手机流程清单，并在获得相应授权后进行真实账号流程验收。

## 开发

项目和缓存保存在 D 盘工作区。Windows 打包、Electron 原生测试及 USB 调试在 Windows 执行；Linux 服务、容器工作优先 WSL2 Ubuntu。本机 Ubuntu 可运行 Git，当前未安装 Node.js。

以下命令在 **PowerShell 7** 执行，需要 Node.js 24+、pnpm 11.25.0 和 PowerShell 7：

```powershell
pnpm install --frozen-lockfile
pnpm prepare:phone
pnpm dev
pnpm test
pnpm build
pnpm package
pnpm verify:release
```

打包完成后运行 `pnpm verify:release`，逐文件核对 ASAR 内的 `core/`、`electron/`、`dist/`、包元数据和许可证，并比较随包 scrcpy 的运行文件及许可证。包元数据使用当前 Electron Builder 的规范化结果；其余核心文件按字节核对。全部通过后才流式计算当前便携版 SHA-256 并更新 `research/release-manifest.json`，缺失、额外或不匹配的核心文件会失败。`pnpm verify:release --check-only` 只检查，不更新清单。

隔离界面测试在 **PowerShell 7** 执行。浏览器测试使用合成账号并拦截外部请求；原生 Electron 测试使用独立账号目录和模拟 IPC，需先构建：

```powershell
pnpm exec playwright install chrome
$env:PLAYWRIGHT_BROWSER_CHANNEL='chrome'
pnpm build
pnpm test:features
pnpm test:resource-retry
pnpm test:hot-topics
pnpm test:media
pnpm test:catalog
pnpm test:app-discovery
pnpm test:user-discovery
pnpm test:community
pnpm test:topic-search
pnpm test:vote-comments
pnpm test:notifications
pnpm test:article
pnpm test:publishing
pnpm test:account-overview
pnpm test:settings
pnpm test:live-photo
pnpm test:goods
pnpm test:secondhand
pnpm test:downloads
pnpm test:sharing
pnpm test:account
pnpm test:account-relations
pnpm test:search
pnpm test:navigation
pnpm test:settings-native
```

已有 Chrome 时可省略安装。媒体测试与 CI 使用 Chrome 验证 MP4；[Playwright 文档](https://playwright.dev/docs/browsers)说明正式 Chrome 与 Chromium 的媒体编解码能力存在区别。`test:settings-native` 保留真实 desktop IPC、原生菜单与缓存接口，以合成账号和网络拦截验证实际窗口。`pnpm test:desktop` 和 `pnpm test:package` 使用隔离账号目录进行公开联网检查。`pnpm test:phone` 打开并随后关闭真实 USB 手机窗口，不支付或执行社交写入。

Git 在 **WSL Ubuntu** 中使用项目路径 `/mnt/d/coolapk desktop`。不要在已有 Windows 依赖目录中混装 Linux 原生依赖。

## 结构与网络

- `core/`：固定接口、认证、账号、搜索、数码/应用、好物、社区、文章、视频、实况和加密账号库。
- `electron/`：受限 IPC、登录/账号/易盾窗口、下载队列、文件保存、USB 协同；前端没有 Node.js 或任意命令权限。
- `src/`：桌面导航、详情、资料、商品清单、下载及媒体编辑界面。
- `scripts/`、`tests/`：测试、只读探测、APK 分析和静态完整性审计。
- `research/`：脱敏报告；`.local/` 保存私有临时文件、截图和工具，默认不入 Git。

API 固定指向酷安服务。公开图片只接受列明的官方 CDN，不带账号凭据；私信图片和账号二维码使用认证接口且不进入公开图片缓存。OSS/COS 上传及 APK 下载校验目标地址，临时密钥不返回界面，Cookie/App Token 不发送给存储或 VOD。账号切换后停止旧请求的后续阶段和未完成下载。导出及原图保存的目标由 Windows 文件对话框选择。远程网页没有主界面桥接权限。程序不收集遥测。许可证见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。
